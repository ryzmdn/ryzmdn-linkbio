# Hello Rizz - Personal Link Bio

A sleek, modern, and highly-optimized personal link-in-bio website. Built with React, TypeScript, Tailwind CSS, and Vite.

## Features

- **Modern UI**: Dark aesthetic with starry backgrounds, shooting stars, and smooth micro-animations.
- **Mobile First**: Fully responsive layout optimized for mobile viewports, tablets, and desktops.
- **SEO & Social Previews**: Pre-configured with Meta tags, Open Graph (OG) tags, and Twitter Card tags.
- **Structured Data**: Built-in JSON-LD Person and WebSite schemas to improve rich snippet visibility on search engines.
- **Search Friendly**: Includes `robots.txt` and `sitemap.xml` configurations.
- **PWA Support**: Standard manifest and shortcut icons configured for modern mobile browsers.

## Tech Stack

- **Core**: React 19 + TypeScript
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS v4
- **Animations**: Motion
- **Icons**: Lucide React

## Getting Started

### Prerequisites

Make sure you have Node.js and `pnpm` (or `npm`) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ryzmdn/ryzmdn-linkbio.git
   cd ryzmdn-linkbio
   ```

2. Install dependencies:
   ```bash
   pnpm install
   ```

3. Start the development server:
   ```bash
   pnpm dev
   ```

4. Build for production:
   ```bash
   pnpm build
   ```
